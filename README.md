# Smart Planner

A simple and convenient web application to organize tasks and boost productivity.

## Features

- **User Management:** Secure login and registration.
- **Kanban Board:** Intuitive drag & drop for tasks, fully supported on mobile devices.
- **Offline Mode:** Create and move tasks without an internet connection, with automatic synchronization upon reconnect.
- **Optimistic UI:** Instant visual feedback without waiting for server responses.
- **Design:** Responsive layout with an integrated dark/light mode.
